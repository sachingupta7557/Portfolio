# Portfolio

A modern, high-performance, and visually stunning personal portfolio built with **Next.js 15**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**. It highlights my technical skills, services, projects, resume, and contact information with custom animations and full screen responsiveness.

## Deployed Site

Here is the live preview of the site:
```text
https://sachin-07.netlify.app/
```

## Features

- **Next.js App Router & TypeScript**: Built on modern React standards with routing and static page optimization.
- **Premium Light Theme**: Designed with custom grid-lines, glowing background blobs, and shadow-elevated card containers.
- **Fully Responsive Design**: Handled responsive margins, fluid images, and stacking button behaviors for seamless mobile, tablet, and desktop layouts.
- **Buttery-Smooth Animations**: Integrated `framer-motion` for page loads, hover card scaling, and intersection triggers on scroll.
- **Custom Typed Text Hook**: A native React typewriter animation replacing legacy script dependencies.
- **Modern Icons**: Powered by `lucide-react`.

## Technology Stack

- **Framework**: Next.js 15 (React 19)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Local Development

Follow these steps to run the project locally:

1. Clone or download this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
4. Build for production:
   ```bash
   npm run build
   ```
