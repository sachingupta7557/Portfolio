# Portfolio

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. It highlights my skills, services, selected projects, resume, GitHub profile, and contact information in a clean single-page layout.

## Live Preview

Add your deployed site link here:

```text
https://sachin-07-portfolio.netlify.app/
```

## Features

- Responsive design for desktop, tablet, and mobile screens
- Smooth scrolling navigation
- Animated typing text in the hero section
- Modern hero section with project highlights
- About section with technical skills
- Services section for frontend, backend, and full stack work
- Project cards with live project links
- Contact section with email and GitHub links
- Lightweight static website with no build setup required

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Typed.js
- Google Fonts
